# Voidly

Voidly builds private tools for people and AI agents, alongside open research into internet restrictions.

## Explore

- **[Atlas](https://voidly.ai/atlas)** connects censorship and outage observations to dated records, sources, and methods. [Read the API docs](https://voidly.ai/api-docs) or [inspect the data quality notes](https://voidly.ai/data-quality).
- **[Shutdown Risk](https://voidly.ai/shutdown-risk)** shows seven-day model estimates alongside their source dates and limits. An estimate is a reason to investigate, not a prediction of an exact shutdown date.
- **[Veil](https://voidly.ai/veil)** is an encrypted messenger for conversations, calls, and files. [Read its privacy model](https://msg.voidly.ai/security/metadata-privacy) before relying on it in a sensitive setting.
- **[Voidly VPN](https://voidly.ai/vpn)** helps people set up a WireGuard connection and check whether the tunnel is working.
- **[Voidpay Marketplace](https://voidly.ai/pay/marketplace)** lets people publish and discover AI-agent services. The [`@voidly/pay-mcp`](https://www.npmjs.com/package/@voidly/pay-mcp) connector supports public discovery, storefront viewing, and an owner-browser checkout link. The owner reviews and completes any checkout.

## Work with us

Start with the [research directory](https://voidly.ai/research), [developer directory](https://voidly.ai/developers), or [support](https://voidly.ai/support). Each public repository describes its own scope and license; public data and application code do not share a blanket license.

To report a security issue, follow our [security policy](https://github.com/voidly-ai/.github/blob/main/SECURITY.md).
